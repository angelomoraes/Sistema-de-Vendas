# Sistema Interativo de Vendas
Sistema completo para:
• **Cadastrar uma venda** em segundos usando um formulário
simples
• **Visualizar todas as vendas** em uma tabela organizada e interativa
• **Acompanhar o faturamento e desempenho** dos vendedores e
produtos no dashboard

O programa:
• Tem uma interface web profissional e interativa que funciona no navegador
• Permite cadastrar vendas com um formulário fácil de usar
• Salva as informações permanentemente em uma base de dados (arquivo CSV)
• Exibe todas as vendas em uma tabela organizada e interativa
• Apresenta um dashboard com métricas de faturamento e gráficos de análise

Disponível na WEB:
**Link:** https://sistema-interativo-vendas.streamlit.app/

Ferramentas Utilizadas:
- Visual Studio Code
- Python 3
- Bibliotecas: pandas, streamlit, plotly
